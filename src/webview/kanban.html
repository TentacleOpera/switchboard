Auto-Archive Rule
Plans that sit in the designated column past the dwell threshold are automatically moved to Completed and archived. Linear/Notion follow via push. Solves the "900 stuck plans vs. Linear free-tier cap" problem by automating the move itself. No backfill — use the manual bulk-archive buttons for the existing backlog.
Default is the column immediately before Completed. Changing the column re-targets the rule immediately. The rule is off by default on upgrade.
