How Linear Remote Control Works
Drive Switchboard completely from Linear without opening the VS Code IDE.

1. Issues Are Plans

Plans live as Linear issues in the mapped Linear project. The issue description contains the implementation plan, goal, and tasks.

2. Status Transitions Drive Execution

Moving an issue between Linear states drives column transitions on the Switchboard Kanban board. When an issue enters an execution-trigger status (e.g. In Progress / Coding), Switchboard dispatches the local column agent to code the solution.

3. Comments Route to the Active Agent

Posting a comment on a Linear issue routes the text directly to the agent assigned to that column. The agent processes your request and posts replies back as issue comments.

4. Startup Reconciler

If you move issues in Linear while Switchboard or VS Code was closed, the startup reconciler picks up the changes on next launch and syncs the board state automatically.
