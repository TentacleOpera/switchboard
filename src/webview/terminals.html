Attaching over SSH

A team is one tmux session with a window per seat. Attach to the team (the base session) and cycle windows with prefix n. Per-seat views run in control mode and share their current-window pointer with a board pane, so attaching to one is not offered here.

The 4-up grid

A plain SSH client shows one seat because the team is four windows, not four panes. The grid button builds a separate grid window whose panes nest-attach to each per-seat view, then hands you the attach command.
Two caveats: nested tmux means two prefixes (Ctrl-b reaches the outer session, Ctrl-b Ctrl-b the inner), and closing the grid window detaches those views without killing the seats.

PTY Fleet Persistence

When enabled, closing or restarting the board leaves the background PTY host and all agent seats running. When you restart the board, it automatically reconnects to the existing seats.
